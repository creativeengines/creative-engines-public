# Brand Knowledge

Brand Knowledge is the product area for organizing approved brand context so every strategy and content task can start from the brand's real material.

Creative Engines should not behave like an empty chat window. It should know which brand it is working for, which source material is approved, and which context should constrain the work.

## What users can do

Brand Knowledge helps users:

- Upload or organize approved source material.
- Keep documents, notes, decks, transcripts, web exports, and brand references tied to the correct brand.
- Preserve source context for later strategy and content work.
- Ground content production in the brand's own language, evidence, and knowledge.
- Archive or update source material as the brand evolves.

Behind the user experience, Creative Engines can use hybrid search and LLM calls to retrieve relevant source material for a task. The public point is simple: the product should bring the right brand context into the work instead of asking the user to paste the same background again and again.

## What it helps decide

Brand Knowledge helps the team decide:

- Which source material should guide a task.
- Whether content has enough grounding to proceed.
- Which claims need support from approved knowledge.
- Which brand facts, examples, or explanations should be reused.
- Where a draft risks becoming generic because it lacks source context.

## How it connects to other product areas

Brand Knowledge supports [Brand Strategy](../brand-strategy/README.md) by giving strategy work a reliable base of context.

It supports [Creative Studio](../creative-studio/README.md) by grounding drafts and reviews in approved source material.

It supports [Editorial Governance](../../concepts/editorial-governance.md) by helping reviewers ask where a claim or decision came from.

## Public boundary

This page explains source grounding at a client level. It does not publish storage details, internal retrieval settings, quality evaluation details, private source-processing steps, or protected knowledge-organization methods.
